# ימי הולדת למקורבים

מערכת לשלוחים למעקב אחרי ימי הולדת (עבריים ולועזיים) של מקורבים ובני משפחותיהם.

## איך זה עובד
- **דף ראשי** (`/`) — הסבר על המערכת וכניסת מנהל. אין בו רשימת קישורים.
- **מנהל** (`/admin`) — יוצר שליח חדש ומקבל קישור אקראי + קוד הפעלה חד-פעמי. המנהל רואה רק שמות וקישורים, **לא את נתוני המקורבים**.
- **קישור שליח** (`/s/<קוד>`) — טופס רישום למקורבים: שם, משפחה, טלפון, תאריך לידה לועזי מלא או עברי (שנה לא חובה), ובני משפחה.
- **כניסת שליח** (`/s/<קוד>/login`) — בכניסה הראשונה מזינים את קוד ההפעלה ובוחרים סיסמה. מאותו רגע רק לשליח יש גישה.
- **דשבורד** — ימי הולדת היום / השבוע / החודש / 30 יום קרובים, גיל, וואטסאפ וחיוג, וכפתור "יצרתי קשר".
- **כרטיס מקורב** — פרטים, יום ההולדת הבא, בני משפחה, היסטוריית יצירת קשר ועריכה.

תאריך עברי מחושב אוטומטית מתאריך לועזי (כולל "נולד אחרי השקיעה"). מי שנולד באדר בשנה פשוטה חוגג באדר ב׳ בשנה מעוברת.
"נוצר קשר" בדשבורד = נרשמה יצירת קשר לאותו אדם החל מ-14 יום לפני יום ההולדת.

## משתני סביבה
| משתנה | תיאור |
|---|---|
| `DATABASE_URL` | חיבור ל-PostgreSQL (ב-Railway: `${{Postgres.DATABASE_URL}}`) |
| `ADMIN_PASSWORD` | סיסמת המנהל |
| `SESSION_SECRET` | מחרוזת אקראית ארוכה |
| `NODE_ENV` | `production` |
| `PUBLIC_URL` | (לא חובה) כתובת האתר, לקישורים שמוצגים למנהל |

הטבלאות נוצרות אוטומטית בעלייה.

## פריסה ב-Railway
1. New Project → Deploy from GitHub repo → לבחור את הריפו.
2. Add → Database → PostgreSQL.
3. בשירות האפליקציה להגדיר את משתני הסביבה למעלה.
4. Settings → Networking → Generate Domain.

## פיתוח מקומי
```
npm install
DATABASE_URL=... ADMIN_PASSWORD=... SESSION_SECRET=... npm run dev
npm test
```
