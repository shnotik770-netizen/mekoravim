# ימי הולדת למקורבים

מערכת לשלוחים למעקב אחרי ימי הולדת (עבריים ולועזיים) של מקורבים ובני משפחותיהם.

## איך זה עובד
- **דף ראשי** (`/`) — הסבר על המערכת, צילומי מסך, דוגמאות לחישוב תאריכים, וכניסת מנהל. אין בו רשימת קישורים.
- **מנהל** (`/admin`) — יוצר שליח: שם השליח, שם בית חב״ד (לא חובה), נייד (חובה) וקוד כניסה קבוע (ריק = אקראי). הקישור הקבוע (`/s/<קוד>`) והקוד נשלחים לשליח ב-SMS מיד ביצירה. מתפריט הפעולות: שליחת הקישור שוב, קוד חדש ושליחה ב-SMS (השרת שומר רק hash, לכן את הקוד הישן אי אפשר לשלוח שוב), עדכון בית חב״ד וטלפון. המנהל רואה רק שמות וקישורים, לא את נתוני המקורבים.
- **כניסה — תמיד בקוד**, ותמיד שתי האפשרויות:
  - **קוד קבוע** — השליח יכול להחליף אותו בהגדרות.
  - **קוד חד-פעמי ב-SMS** לנייד השליח: 6 ספרות, תוקף 10 דקות, עד 5 ניסיונות לקוד, עד 3 שליחות ב-15 דקות. מי שנכנס כך (למשל ששכח את הקוד) יכול ב-15 הדקות הבאות לקבוע קוד חדש בלי הקוד הנוכחי.
  - החלפת קוד או נייד מנתקת את כל המכשירים המחוברים.
- **שליח** (`/s/<קוד>`) — דשבורד, מקורבים, קישורי רישום והגדרות.
- **הוספת מקורבים** בשתי דרכים: השליח ממלא בעצמו מהדשבורד, או יוצר **קישור רישום** (`/r/<קוד>`) ושולח למקורבים. אפשר כמה קישורים, ולכל אחד סיווג אוטומטי.
- **ייבוא מאקסל** (`/s/<קוד>/contacts/import`): מעתיקים טבלה מאקסל / Google Sheets (או CSV) ומדביקים. זיהוי עמודות אוטומטי לפי כותרות (שם פרטי, שם משפחה, שם מלא, טלפון, תאריך לידה, יום/חודש/שנה עברית, אחרי השקיעה, סיווג, הערות) או לפי התוכן, עם אפשרות לתקן. תאריכים: לועזי (14/03/1990, 14.3.90, 1990-03-14, מספר סידורי של אקסל) או עברי ("ה׳ חשוון תש״נ", "כ״ט באדר א׳ תשמ״ד"). תצוגה מקדימה עם מצב לכל שורה; שורות עם שגיאה וכפילויות (לפי טלפון, או שם + תאריך עברי) מדולגות. עד 2000 שורות בפעם.
- **סיווגים** — לכל מקורב סיווג (שם + צבע, ניתן לעריכה בהגדרות); סינון בדשבורד וברשימה.
- **רק יום הולדת עברי** נחשב. תאריך לועזי משמש רק להמרה (כולל "נולד אחרי השקיעה") ומוצג לידיעה.
- **דשבורד** — היום / השבוע (ראשון–שבת) / החודש העברי / 30 יום קרובים, גיל, וואטסאפ וחיוג, "יצרתי קשר".

### תזכורות SMS (ימות המשיח)
השליח מזין בהגדרות נייד ובוחר תזכורות — אחת או שתיהן:
- **שבועי** — ביום ראשון מהשעה `SMS_HOUR`: כל ימי ההולדת של השבוע (ראשון–שבת).
- **יומי** — בכל יום חול מהשעה `SMS_HOUR`: ימי ההולדת של היום. ביום בלי ימי הולדת לא נשלחת הודעה.

**תזכורת אישית על מקורב:** בכרטיס המקורב בוחרים "🔔 תזכורת SMS על יום ההולדת" — ביום עצמו או 1–7 ימים לפני. נשלחת לנייד השליח (נייד ה-SMS, ואם אין — הנייד הראשי) **גם אם התזכורות הכלליות כבויות**, הודעה אחת לכל המקורבים שמגיע תורם באותו יום, עם הטלפון של המקורב. כשיום התזכורת בשבת/חג — ביום החול שלפניו. יורדת ממכסת התזכורות; טבלת `contact_reminders` מונעת כפילות. לא ניתן להפעיל דרך טופס הרישום הציבורי.

**שבת וחג:** בשבת וביום טוב (לוח ארץ ישראל, לפי hebcal) לא שולחים. ביומי — ההודעה של ערב שבת/חג כוללת גם את ימי השבת/החג שאחריו (למשל ערב ראש השנה שחל בשישי: שישי+שבת+ראשון). בשבועי — כשיום ראשון הוא חג, ההודעה נשלחת ביום החול שלפניו.

**מכסת יחידות לתזכורות:**
- רק **תזכורות ימי הולדת** יורדות ממכסת השליח (`sms_quota` = הוקצו, `sms_used_birthdays` = נוצלו). הודעות מערכת — קוד כניסה, פרטי כניסה, הודעת ניסיון — על חשבון המערכת.
- יחידה = 70 תווים בעברית (67 לכל חלק בהודעה ארוכה). הניכוי אטומי לפני השליחה ומוחזר אם השליחה נכשלה.
- המכסה לא מתאפסת אוטומטית: המנהל מוסיף יחידות (או קובע מכסה כוללת) מתפריט הפעולות. לשליח חדש — המכסה ההתחלתית שבראש מסך הניהול (`app_settings`), או מה שהוזן ביצירה.
- **דשבורד השליח** מציג הוקצו / נוצלו / יתרה. כשהיתרה יורדת אל הסף (`sms_alert_threshold`, ריק = 10% מהמכסה) מוצגת התראה בראש הדשבורד; ביתרה 0 התזכורות האוטומטיות נעצרות עד הוספת יחידות.
- כל שליחה נרשמת בטבלה `sms_log`.

השליחה דרך `SendSms` של ימות המשיח (POST JSON: `token`, `phones`, `message`, `from`) — ראו הסקיל `.claude/skills/yemot-hamashiach-api`. בהגדרות יש תצוגה מקדימה וכפתור "שליחת הודעת ניסיון". שגיאה אחרונה מוצגת לשליח.

### כללי תאריכים (כמו בפרויקט קאפיטל)
- אדר בשנה פשוטה → בשנה מעוברת נחגג באדר ב׳; אדר א׳/ב׳ בשנה פשוטה → אדר. גם כאן התווית היא התאריך המקורי, עם הערה על התאריך של השנה.
- ל׳ בחודש שאורכו משתנה (חשוון, כסלו, אדר א׳) → בשנה שאין בה ל׳, מציינים יום קודם (כ״ט). התאריך מוצג תמיד כמקורי ("ל׳ חשוון"), עם הערה "השנה אין ל׳ חשוון — מציינים בכ״ט חשוון".
- "ל׳ אדר" = ל׳ אדר א׳ (רק לו יש 30 ימים).
- תאריך שלא קיים כלל (ל׳ טבת/אייר/תמוז/אלול/אדר ב׳) נחסם; עם שנה — נבדק אורך החודש באותה שנה.
- "נוצר קשר" בדשבורד = נרשמה יצירת קשר לאותו אדם החל מ-14 יום לפני יום ההולדת.

## יומן פעולות וסטטיסטיקות (למנהל)
- **יומן פעולות** (`/admin/log`): כל פעולה במערכת — מנהל, שליח, רישום ציבורי בקישור ומערכת (תזכורות SMS, שגיאות שרת, הפעלה). סינון לפי שליח ו"רק תקלות וכישלונות". בראש מסך הניהול: שלוחים פעילים, מקורבים במערכת, יחידות SMS החודש ותקלות ב-24 השעות האחרונות.
- **דשבורד לכל שליח** (`/admin/shluchim/:id`, בורר למעבר בין שלוחים): "בריאות החשבון" עם התראות אוטומטיות (מושבת, אין נייד/קוד קבוע, לא נכנס 30 יום, אין מקורבים, יתרת SMS נמוכה/נגמרה, שגיאת SMS, כניסות שנכשלו, כיסוי "יצרתי קשר" נמוך); מדדים — ימי הולדת היום/השבוע/החודש/30 יום (ספירות בלבד), אחוז "יצרתי קשר" על ימי ההולדת של 30 הימים האחרונים, כניסות, מקורבים ובני משפחה, יתרת SMS; גרפים — פעילות לפי שבוע, מקורבים חדשים לפי חודש, יחידות SMS לפי חודש; והיסטוריית הפעולות.
- **פרטיות:** בפעולות של שליח ושל רישום ציבורי נשמרים רק סוג הפעולה והתוצאה (הצליח / נכשל / נחסם / תקלה) — לעולם לא שמות, טלפונים, הערות, שמות סיווגים או טקסט שהוקלד. פרטים נשמרים רק בפעולות מנהל ומערכת, ומספרים ארוכים עוברים מיסוך. בשגיאות שרת נשמרים רק הנתיב הכללי וסוג השגיאה. הסטטיסטיקות הן ספירות בלבד. הרשומות נמחקות אחרי 180 יום (טבלה `activity_log`, ראו `lib/audit.js`).

## משתני סביבה
הוראות מלאות להגדרה ב-Railway: [`docs/DEPLOY.md`](docs/DEPLOY.md).

| משתנה | תיאור |
|---|---|
| `DATABASE_URL` | חיבור ל-PostgreSQL (ב-Railway: `${{Postgres.DATABASE_URL}}`) |
| `ADMIN_PASSWORD` | סיסמת המנהל. בפרודקשן: 8 תווים לפחות, לא רצף ולא תו חוזר — אחרת השרת לא עולה |
| `SESSION_SECRET` | מחרוזת אקראית, 32 תווים לפחות בפרודקשן |
| `NODE_ENV` | `production` |
| `PUBLIC_URL` | כתובת האתר (לקישורים, וגם לקישור לדשבורד בתוך ה-SMS) |
| `YEMOT_TOKEN` | מפתח API של ימות המשיח (`apik_...`; גם `מספר_מערכת:סיסמה` עובד). בלי זה ה-SMS כבוי |
| `YEMOT_SMS_FROM` | (לא חובה) מזהה שולח מאושר במערכת ימות המשיח |
| `SMS_HOUR` | (לא חובה) שעת השליחה ביום ראשון, שעון ישראל. ברירת מחדל 8 |
| `YEMOT_API_URL` | (לא חובה) ברירת מחדל `https://www.call2all.co.il/ym/api` |

הטבלאות נוצרות ומתעדכנות אוטומטית בעלייה. **שירות אחד בלבד** (replicas=1) — הגבלות הקצב נשמרות בזיכרון.

## עיצוב
מבוסס על חבילת העיצוב של המעצב: `public/css/tokens.css` ו-`public/css/components.css` (כמו שהם), ו-`public/css/app.css` להשלמות במסכים שהחבילה לא עיצבה. כל הצבעים במשתני `--bd-*`, כולל מצב כהה אוטומטי. התאריכים מחושבים בשרת (hebcal); `hebrew-date.js` מהחבילה לא בשימוש.

## גיבוי
`scripts/backup.mjs` מייצא את כל הטבלאות ל-JSON דחוס ושומר ב-bucket (S3) — רץ כשירות cron יומי, שומר 30 יום. `scripts/restore.mjs` משחזר (דורש `CONFIRM=yes`). להגדרה: [`docs/DEPLOY.md`](docs/DEPLOY.md) סעיף 6. לבדיקה מקומית: `BACKUP_DIR=/tmp/bk`.

## פריסה ב-Railway
ראו [`docs/DEPLOY.md`](docs/DEPLOY.md).

## פיתוח מקומי
```
npm install
DATABASE_URL=... ADMIN_PASSWORD=... SESSION_SECRET=... npm run dev
npm test
```

צילומי המסך בדף הבית נוצרים ע"י `scripts/screenshots.mjs` (מול שרת מקומי עם DB ריק, דורש playwright).

בקשה למעצב: `docs/designer-brief.md`.
